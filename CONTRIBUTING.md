# Contributing

A personal project developed in the open. External contributions are not accepted yet;
issues and discussion are welcome.

## Development environment

`nix develop` provides Rust, Go, buf, the protoc plugins, cargo-fuzz and nushell. No other
toolchain is supported.

## Checks

```sh
nix flake check   # lint, tests, module evaluation, nixosTest (Linux with kvm only)
nix fmt           # treefmt: rustfmt, gofmt, nixfmt
```

## Protobuf

After editing a `.proto` file: `cd proto && buf lint && buf generate`. The Go client under
`apps/cli/internal/genproto/` is committed; the Rust code is generated by
`crates/kekkai-control/build.rs` at build time.

## Versioning

One semver version in `VERSION`, mirrored in `Cargo.toml` (`[workspace.package].version`) and
`apps/cli/internal/version/version.go`. The `versions-identical` check fails on drift (ADR 0024).
