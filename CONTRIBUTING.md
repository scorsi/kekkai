# Contributing

A personal project developed in the open. External contributions are not accepted yet;
issues and discussion are welcome.

## Development environment

`nix develop` provides Rust, buf, protoc, cargo-fuzz and nushell. No other
toolchain is supported.

## Checks

```sh
nix flake check   # lint, tests, module evaluation, nixosTest (Linux with KVM only)
nix fmt           # treefmt: rustfmt, nixfmt
```

## Protobuf

After editing a `.proto` file: `cd proto && buf lint`. The Rust code (server and client) is
generated by `crates/kekkai-control/build.rs` at build time; nothing generated is committed. A
new field or enum value needs a `status --json` fixture under `apps/cli/testdata/status/`,
written by hand (ADR 0033).

## Versioning

One semver version in `VERSION`, mirrored in `Cargo.toml` (`[workspace.package].version`) and
inherited by every binary. The `versions-identical` check fails on drift (ADR 0024).
